SDO/AIA Carrington Synoptic Map Archive

A reproducible, multiwavelength archive of solar synoptic maps constructed from observations by the Atmospheric Imaging Assembly (AIA) aboard NASA's Solar Dynamics Observatory.

Providing Carrington-coordinate intensity maps, uncertainty characterization, quality-control products, and processing metadata.

Archive Overview

The archive provides standardized Carrington synoptic-map representations for seven EUV and two UV channels, supporting studies of long-term solar atmospheric variability and reproducible multiwavelength analysis.

Seven EUV Channels

Coronal and transition-region emission observed by AIA.

94 Å 131 Å 171 Å 193 Å 211 Å 304 Å 335 Å

Two UV Channels

Baseline intensity and separately identified center-to-limb-variation-relative products.

1600 Å 1700 Å

Spatial Representations

CAR (linear-latitude) and CEA (equal-area) map representations, each using a 1440 × 2891 grid.

CAR CEA

Scientific Data Products

Quantitative data products are provided in FITS format. PNG quicklooks are intended for visual inspection, not quantitative scientific analysis.

Intensity Maps

Exposure-normalized intensity synoptic maps in DN s⁻¹, in CAR and CEA representations.

Uncertainty Products

Measurement uncertainty, synoptic dispersion, and combined internal uncertainty for scientific analysis.

Quality and Provenance

Contribution counts, effective samples, weights, temporal diagnostics, and processing metadata.

Interactive Map Explorer

The planned browser will support selection by wavelength, Carrington rotation, projection, and product type, with map previews and scientific file downloads.

Map browser in preparation

The archive catalog and public download endpoints are being prepared. FITS and full-resolution PNG links will be activated after data release.

Documentation and Reproducibility

Documentation will include processing methods, FITS/WCS descriptions, uncertainty definitions, quality-control metrics, software, and dataset citation information.

Repository and documentation

The website source is maintained in a public GitHub repository. Release metadata and scientific citations will be added as the archive is finalized.
